# LLM prompts used for Lab 4

These prompts follow the README tasks and keep the original project structure.

1. **Inspect and reproduce the defect**
   > Read the README and inspect `main.py`, `game.py`, `board.py`, and `ai.py`. Explain how a move reaches winner detection. Identify the existing defects without replacing the project or adding dependencies. Demonstrate why diagonal wins are currently missed.

2. **Task 1: win detection**
   > Update `Board.winner` to detect horizontal, vertical, and both diagonal four-in-a-row lines. Keep boundaries safe and ensure runs shorter than four do not win.

3. **Task 2: termination and invalid moves**
   > Make the game handle invalid text, out-of-range columns, full columns, draws, wins, quitting, and closed input consistently. Invalid input must not change the board, and a win must end before another prompt.

4. **Task 3: AI decisions**
   > Improve the AI so it takes an immediate winning move, blocks an immediate opponent win, never chooses a full column, and returns no move when the board has no legal columns. Keep the implementation understandable and dependency-free.

5. **Task 4: move feedback**
   > Add one concise message for each successfully placed disc. Do not print move feedback while inspecting candidate moves or checking for wins.

6. **Review and acceptance checks**
   > Review the changes against every README task. Check horizontal, vertical, both diagonals, runs shorter than four, full board, full/invalid columns, invalid text, quit, AI immediate win/block, and that a winning move stops immediately. Explain any remaining submission steps.
